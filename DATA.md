# Data

This repository contains analysis code, the manuscript, and auditable evidence tables. It does **not** contain the raw public datasets. To reproduce, stage the following public inputs under `inputs/` (each script records its exact expected path; a few scripts redact the machine-specific prefix to `<PROJECT_ROOT>` — set it to your local checkout root).

| Dataset | Source | Used for |
| --- | --- | --- |
| EPA LMOP Landfill and Project Database | https://www.epa.gov/lmop/lmop-landfill-and-project-database | landfill registry (status, dates, Landfill/Project IDs) |
| EPA GHGRP Subpart HH — landfill gas collection | https://www.epa.gov/ghgreporting (Envirofacts download) | gas flow, methane concentration, recovered CH4 |
| HIFLD Natural Gas Pipelines | https://hifld-geoplatform.opendata.arcgis.com/ | pipeline proximity / distance |
| EIA-923 (electricity / fuel use) | https://www.eia.gov/electricity/data/eia923/ | landfill-gas energy generation |
| BTS/EIA 2020-01 pipeline layer | https://geo.dot.gov/server/rest/services/BTS/NaturalGas_Pipelines_US_202001/MapServer | 2020 landmark (time-ordered) analysis |

All sources are public U.S. government data. Facility-level landfill records are public under EPA reporting. No non-public or personally identifiable data is included in this repository.

## Derived evidence tables (committed)

- `rng_mainline_strengthening_v1/event_ledger.csv` — per-project first-injection event ledger (registered dates plus externally supported date bounds).
- `rng_mainline_strengthening_v1/source_ledger.csv` — source locations and audit status for each adjudication.
- `rng_mainline_strengthening_v1/deployment_comparisons.csv` — deployment counts and distance estimates across event-definition rules.

Full per-run outputs are regenerated by the scripts (see `rng_mainline_strengthening_v1/README.md` for the reproduction recipe) and are not all committed here.

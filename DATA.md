# Public inputs and preserved evidence

The locked deployment model uses the EPA's September 2024 LMOP workbook and one HIFLD archive. Keep the downloaded files in `data/raw/` or select an existing read-only copy in `config/paths.local.toml`. [Exact input manifest](config/public_inputs.json) records the URLs, filenames and SHA-256 digests.

`python scripts/download_public_data.py lmop` and `python scripts/download_public_data.py hifld_archive` stage the two mainline inputs. `--from-local PATH` stages an existing copy with the same verification. An upstream file that no longer matches the manifest requires retrieval of the documented historical version. The script leaves any existing file in place and reports the mismatch. The independently packaged EIA archive requires `--from-local`.

The HIFLD ZIP supplies the `natural-gas-interstate-and-intrastate-pipelines.shp` member, SHA-256 `de6c0c45fe33b4bc1ae033f13059d8514245e30604bf1c5d9df90466aeb92e6a`. The pipeline writes it and the rederived LMOP facility frame and distances beneath `data/derived/build/`. [Evidence catalog](evidence/README.md) locates the inherited adjudications and model-check references. These evidence decisions are part of the locked specification.

The frozen [temporal result](rng_mainline_strengthening_v1/results/temporal/run_007/landmark2020_models.csv) ships as an archive. Facility-reported methane and electricity analyses use public [EPA GHGRP Subpart HH](https://www.epa.gov/ghgreporting) and [EIA-923](https://www.eia.gov/electricity/data/eia923/) releases. They are outside the required input set for `run_all.py mainline`.

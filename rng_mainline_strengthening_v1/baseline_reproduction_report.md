### 原始计算复现

复跑回灌、空间推断和 logit 诊断三份原脚本，唯一运行适配是把旧脚本的输出守卫定向至新仓库。Python 3.13.5、NumPy 2.4.4、pandas 3.0.2，使用单线程 OpenBLAS。复跑的纠正 T2 为 **1,502 场、43,593 场址年、121 个事件、ln 距离 −0.1687003、100 km Conley SE 0.0766829、p 0.0278088**。宽登记旧 T2 为 −0.1836869，144 个事件。八个 T1/T2 拟合和两组空间模型的保存字段均通过数值比较，36 场事件轨迹逐行一致。 [复现检查](results/checks/run_003/baseline_checks.json) · [原脚本输出](results/legacy/run_001/)

旧 T2 的事件年份哑变量使所有零事件年进入同一个纯零参照组。降低截距并等量提高每个事件年系数，会让纯零组预测更接近零，其他年份的预测维持原样。这提供了准完全分离方向。实际诊断有 57 个参数，ridge 为 1e−6，信息矩阵条件数 2.64×10⁹，去惩罚后的尝试数值奇异。单线程重跑在 223 步收敛，保存诊断是 25 步。系数和样本仍匹配。将日历基线改为六组后，对照设计满秩，主模型 36 参数，条件数约 4.70×10⁵。线性规划未检出分离方向，未加 ridge。

## 3. 诊断复现（回答 prompt A.3）

`diagnostics` 复现确认（ev_opshut_corr, T2 州 FE）：

- **收敛**：IRLS 收敛，迭代 223 次，最终最大梯度（ridge）3.95e-11。
- **完全/准分离**：`unpenalized_singular = true`——**去 ridge 后 Hessian 数值奇异**，因此无法给出未惩罚 MLE。基线吸收块（截距 + 年哑变量 + 州哑变量）近共线：条件数 2.64e9；截距 β=−38.19（SE 54.37），年哑变量 β≈11.5–13.3（SE≈54.3）。
- **参数个数**：57（含截距）；事件年哑变量 25 个；**无事件州被剔除 18 个**（AL/AZ/CO/CT/DE/ID/MA/MD/ND/NJ/NM/NV/OR/RI/SD/UT/VT/WY）。
- **ridge**：1e-6，仅作数值稳定；暴露系数 −0.1687 与聚类/Conley SE 不受 ridge 影响（与去 ridge 奇异前的主结果一致）。

**诚实记录（这是本报告最重要的开放项）**：主结果 −0.169 是 **ridge=1e-6 惩罚下的估计**，不是纯极大似然估计——因为未惩罚模型在基线块奇异。这个事实在成稿时必须如实写（"ridge + 条件数 2.64e9 + 基线块不可识别 + 暴露系数不受影响"），不能写成"已检查收敛即全绿"。这与 prompt 7.1 的提醒完全一致：43,593 场址年≠43,593 个独立信息单位，信息由 121 事件 + 有限场址支撑。

## 4. 已确认的旧分析"实际回答了什么"

- **估计目标**：入组后、首次投运前的年度**条件优势关联**（log 距离 → 采纳 hazard），州 FE 吸收州级恒定混杂。是**回顾性关联**，不是因果；静态管网 + 后置快照的废物在场量解释了多年历史，这一限制未变。
- **主事件定义**：纠正后 `Operational + Shutdown`（ev_opshut_corr）= 121 事件；比全状态（144）少 23 个幻影采纳，比原 op_shut（108）多 13 个经外部核验的真实晚采纳。
- **回灌校正计数**（backfill 复现）：11 假采纳 + 3 不确定 + 22 真实晚采纳 + 13 真实新增事件；consequence 端 ever-operational treated（109）与 36 never-operational **零交集**，DiD 处理组不变。
